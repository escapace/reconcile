# Interleaved isolated-arm comparison

No measurement has run. The whole round requires explicit coordinator GO and an outer295-second process-group deadline, including descendant cleanup. Internal startup/IPC waits use the remaining285-second deadline; a timeout is incomplete evidence, not a pass.

Each of22 fixtures has two independent process clusters. Each cluster starts four children serially and waits for ready: A, exact A copy, restored baseline and exact baseline copy. Every child loads only its own combined encode/decode bundle, creates its own input and encoded text, checks graph fidelity, and performs the same initial GC before ready. All startups finish before warmup. Each child retains one latest output sink. No selective GC, arbitrary sleeps, global scheduling changes or engine single-threaded flags are used. Inactive children wait for JSON-line commands; Node background GC/helper work can still occur.

The parent requests one arm at a time. Every operation has three interleaved50ms warmup segments per arm, ensuring at least150ms and three calls. Six timed40ms blocks follow. A seeded arm-label permutation maps Williams rows `[0,1,3,2]`, `[1,2,0,3]`, `[2,3,1,0]`, `[3,0,2,1]` to actual orders, indexed by `(rep*6+block)%4`. Across two clusters, twelve blocks place each arm in each position three times and each ordered within-block predecessor pair three times. Actual orders are recorded. Fixture/cluster ordering and operation ordering are seeded and recorded.

Workers are pinned to CPU4 only if it is allowed and taskset is available; actual affinity is recorded. This does not establish host isolation. All warmup and timing observations are retained, including outliers. Each block records wall time, process.cpuUsage and cgroup cpu.stat before/after. Cgroup counters cover the whole container, not just the child, and CPU/wall differences do not identify a specific cause. Per-child memory.events before/after are likewise shared-container observations and must not be summed across overlapping lifetimes.

Analysis nests six blocks within each of only two independent clusters. Twelve block ratios are not twelve independent process samples.
